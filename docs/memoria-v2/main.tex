% es digital (RUA), no hay encuadernación y esas blancas no aportan.

% La plantilla por defecto deja casi un tercio de página en blanco antes
% del nombre del capítulo, lo que hace que en pantalla se vean huecos
% gigantescos. Comprimo el bloque a un único \vspace ligero.
\RedeclareSectionCommand[
  beforeskip=-1pt,
  afterskip=24pt
]{chapter}
\renewcommand*{\chapterheadstartvskip}{\vspace*{1.5\baselineskip}}

% Bibliografía
